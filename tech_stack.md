## afcon25morocco 
### The Technology Stack

* **Core Framework:** React 18 with strict TypeScript.


* **Build Tool & Dev Server:** Vite v4.


* **Routing:** React Router DOM (with route-level code splitting using `lazy` and `Suspense`).


* **Styling:** Tailwind CSS and daisyUI component primitives.


* **UI Primitives:** shadcn/ui (Radix UI primitives under the hood).


* **Animations:** Framer Motion (for page transitions).


* **Icons:** Lucide React.


* **Data Layer:** Purely static, local immutable `.json` files baked right into the client code.
* **Image Pipeline:** Global client-side URL masking via `wsrv.nl` to clear hotlink locks and compress assets on the fly.
* **Hosting:** Vercel Global Edge CDN.
